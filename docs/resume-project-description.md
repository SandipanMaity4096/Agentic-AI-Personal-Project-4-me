# Resume Project Description

## Project Title
Agentic AI Customer Support Chatbot

## Resume Bullet Version
- Engineered a multi-agent AI customer support system using Python, Streamlit, LangChain, ChromaDB, and SQLite to automate query handling with RAG-grounded responses and intelligent escalation.
- Designed specialized agents for intent detection, sentiment analysis, FAQ retrieval, and human handoff decisioning, improving response consistency and auditability.
- Implemented conversation memory, ticket auto-creation simulation, and dashboard analytics to demonstrate enterprise-ready support operations.
- Built a provider-agnostic LLM layer compatible with OpenAI, Gemini, and Ollama for deployment flexibility.

## LinkedIn/GitHub Description
This project demonstrates an enterprise-style Agentic AI workflow for customer support. It uses multi-agent orchestration, retrieval-augmented generation (RAG), memory, and automated escalation logic to simulate real support operations with a modern dashboard UI.
